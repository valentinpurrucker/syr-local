# Changelog

## 0.2.0

- Integration: new `custom:syr-local-card` dashboard card, served and loaded by
  the integration itself. One compact overview with status, resin, salt, flow,
  today's water use, last regeneration, an hourly 24 h graph and counters;
  visual editor in the card picker.
- German translation for the integration (entity names, setup, errors), the
  card and the add-on options.
- Add-on: no functional change; version bumped to stay in step with the
  integration.

## 0.1.0

- First release: read-only local stand-in for syrconnect.de (LEXplus10S),
  state API v1, Supervisor discovery for the SYR Local integration.
